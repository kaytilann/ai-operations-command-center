# KPI Framework

## North Star Metric
Operational margin protected through AI-assisted decisions.

## Input metrics
- Data freshness
- Connected systems count
- Forecast coverage
- Incident detection coverage
- Query volume
- Recommendation generation volume

## Product usage metrics
- Weekly active users
- Copilot queries per user
- Scenario simulations run
- Executive briefs exported
- Recommendation click-through rate
- Workflow actions initiated

## AI quality metrics
- Recommendation acceptance rate
- Recommendation override rate
- Root-cause accuracy
- False positive incident rate
- False negative incident rate
- Confidence calibration
- Human review escalation rate

## Business outcome metrics
- OTIF improvement
- Cost/order reduction
- Fulfillment cycle time reduction
- Stockout rate reduction
- Excess inventory reduction
- Working capital released
- Revenue protected
- Margin protected

## Guardrail metrics
- Customer promise misses
- Operational incidents caused by AI recommendations
- User trust score
- Data quality failure rate
- Low-confidence recommendation rate
- Model drift indicators
