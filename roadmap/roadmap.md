# Roadmap

## Phase 0: Concept validation
- Interview operations leaders.
- Gather examples of recent incidents.
- Map systems and data availability.
- Define MVP metrics.

## Phase 1: High-fidelity prototype
- Build executive dashboard.
- Build AI incident cards.
- Build Ops Copilot experience.
- Create scenario simulator.
- Validate with target users.

## Phase 2: Historical data pilot
- Connect historical OMS/WMS/carrier extracts.
- Backtest anomaly detection.
- Compare AI root cause against postmortems.
- Measure time-to-diagnosis improvement.

## Phase 3: Live limited pilot
- Monitor one region or facility.
- Generate recommendations without automated execution.
- Track user acceptance and override reasons.
- Improve confidence calibration.

## Phase 4: Workflow integration
- Add Jira/Slack/email handoffs.
- Add approval workflow.
- Add executive summary export.
- Add audit trail.

## Phase 5: Controlled automation
- Allow low-risk automated actions.
- Introduce policy-based guardrails.
- Expand to inventory, labor, and carrier optimization.

## Future bets
- Autonomous replenishment recommendations
- Dynamic carrier routing
- AI-generated board operations update
- Margin-aware demand shaping
- Cross-functional operations agent
